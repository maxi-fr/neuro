## Problem Statement

The experiment should inform how far ahead an MPC Predictor can usefully look and which EEG-derived suppression penalty is worth pursuing. The current notebook mixes candidate signals, seizure readout scores, and normalized replicate spread under the term “metric.” Its connectivity calculation averages absolute Pearson correlations, so common-source projection can increase the score and changes in individual channel pairs are lost. The current runner generates rollouts while the notebook orchestrates much of the analysis.

## Solution

Renew the ensemble runner, the interactive state-scoring notebook, the meeting presentation notebook, and their backend around one reproducible experiment. Compare Waveform samples, spectral Observable Frames, and functional-connectivity Frames in matched plots over physical lookahead. Use the corresponding suppression penalties to evaluate seizure relevance and paired stimulation response. Preserve the meeting's emphasis on reading the curves to make a decision about useful lookahead.

## Implementation Decisions

1. **Freeze the protocol.** Package a local Plant configuration, experiment configuration, and reference configuration with the run. Record Plant and noise seeds, branch definitions, arm currents, channel order, effective sampling rates, Frame geometry, reference provenance, and schema version. Use the same generated rollouts across the three representations. Retain the existing branch schedule and arm allocation as the starting protocol, but show realized starting Seizure State and report arm coverage. Compare arms only on a common set of snapshots when making a head-to-head contrast.
2. **Preserve the paired design.** Generate independent parent runs, then branch from a complete Plant snapshot and vary future noise across replicates. Reuse the same noise realization across arms within each snapshot and replicate. Key data by Plant kind, parent seed, branch, replicate, and arm. Join by these identities and reject incomplete or duplicate pairs. Use separate healthy reference seeds and freeze estimator settings on development seeds before reporting held-out results.
3. **Make the branch boundary explicit.** Carry real pre-branch scalp EEG and regional LFP. The scalp prefix must cover estimator warm-up and the longest configured trailing support. Carry causal filter state or process the shared history before replaying each continuation. Compute Seizure State with the existing regional threshold and trailing window. Record sample and Frame endpoint times relative to the branch and mark the interval in which shared history still contributes to each quantity. Set the rollout duration to cover the Control Horizons being discussed. Compare values at common physical times where the grids align and preserve native grids otherwise.
4. **Extract three representations.** Use controller-equivalent filtering, channel order, and sampling for Waveform samples. Use the canonical causal spectral transform and configured Frame geometry for spectral log power. For connectivity, start with signed imaginary coherency in the configured seizure band. Estimate auto- and cross-spectra from multiple tapered segments contained in each trailing window, normalize the cross-spectrum by the square root of the product of the auto-spectra, then take its imaginary part and average across the band. Keep the unique off-diagonal channel pairs in a fixed order. Record window, segment, taper, overlap, hop, band, and power validity rule. Treat unsupported or low-power estimates as missing and report coverage. Choose the shortest candidate support that gives repeatable healthy estimates on development runs and report it against the Control Horizon. If none qualifies, report the connectivity limitation with its evidence.
5. **Define predictability on the representations.** For each branch and lookahead on the zero-current arm, compute sample variance across noise replicates within each parent snapshot, average the variances over parents and valid components, then take the square root. Retain component identities through the variance calculation so waveform sign, spectral bins, and connectivity edges are preserved. Plot the result in native units. For a shared dimensionless panel, divide by a frozen development-set RMS component standard deviation for the corresponding representation and report that reference scale and the effective support counts. A zero reference scale makes the normalized result undefined. Label these curves as conditional replicate spread with the full Plant snapshot fixed. Mark the physical Control Horizons and the shared-history intervals.
6. **Define three suppression penalties.** For each measured Waveform sample, average squared deviation from the healthy channel means. For each measured spectral Frame, average squared positive log-power excess above the configured healthy channel-by-frequency envelope. Use the existing MPC references and reductions for both, with numerical parity at the sample or Frame level before horizon weights. For each measured connectivity Frame, average the squared distance of each pair's value outside its healthy interval, with zero inside. Start with independently fitted fifth and 95th percentiles per pair, frozen before evaluation. Aggregate over a fixed eligible pair set, and mark the aggregate missing if any eligible pair is invalid in that Frame. Fit eligibility on healthy development runs and report Frame coverage. Keep current effort and terminal weighting outside these suppression penalties.
7. **Measure seizure relevance and response separately.** On zero-current runs, plot measured penalty against aligned Seizure State, showing onset and recruitment separately from saturated and healthy activity. Under stimulation, subtract the matched zero-current trace from each penalty and from Seizure State at each lookahead. Show signed mean effects and Plant-seed bootstrap intervals, keeping all branches and replicates of each resampled parent together. Show paired penalty and Seizure State changes jointly at declared Control Horizons, including the fraction of pairs with reduced penalty and unchanged or increased Seizure State. Report undefined associations when either variable lacks variation. Preserve branch strata and indicate untested arms explicitly.
8. **Split generation, analysis, and rendering.** Reuse the existing Plant snapshot and replay machinery. Keep representation extraction, healthy reference fitting, penalty evaluation, and scoring in the backend. Have the runner expose a dry-run plan, generation, and scoring entry points with a shared configuration. Dry-run estimates must include history storage and identify the analysis geometry. Publish a complete manifest only after generation succeeds. Invalidate score caches when their source manifest, representation settings, or references change. Require regeneration when an archive lacks the histories or identity keys needed by the renewed analysis. Audit existing consumers before removing the legacy scoring paths and preserve interfaces still used outside this experiment.
9. **Renew both notebooks around the same output.** The state-scoring notebook loads scored artifacts and exposes phase, arm, representation, and horizon selections for exploration. The meeting notebook uses the same plot builders and fixed, recorded selections for a repeatable presentation. Order the views as conditional replicate spread over lookahead, unstimulated penalty against Seizure State, then paired response over lookahead. Keep plot inputs inspectable and exportable for the thesis. Recover the original meeting notebook or a rendered copy before verifying visual parity.
10. **Implement in verifiable slices.** Start with the tiny paired runner-to-report acceptance test. Add the history and identity contract, then Waveform and spectral parity, then the new connectivity extraction and penalty. Wire the shared outputs into both notebooks after the numerical tests pass. Run the full experiment after the smoke run is green and record the data-supported Control Horizon and penalty conclusions with the packaged results.

## Testing Decisions

- The primary seam is the runner-to-report flow agreed for this draft. A tiny seeded ensemble with multiple parents and replicates, a zero arm, and a stimulation arm must generate, score, and render the shared plots. Check exported times, arm coverage, sign of contrasts on a controlled fixture, and agreement between the interactive and meeting plot inputs. Use the existing ensemble-generation and paired-noise tests as prior art.
- At the public extraction seam, identical history and continuation must agree with causal extraction on the joined signal. Changing future samples must leave earlier outputs fixed. Test the first valid endpoint, native grid alignment, and reported history support. Check spectral parity against the canonical transform. For connectivity, use synthetic in-band signals with a known lag, zero-lag mixtures, a swapped pair, and a low-power case. Expect near-zero imaginary coherency for the zero-lag fixture, sign reversal on pair swap, and explicit missingness for invalid power.
- At the scoring seam, hand-compute replicate spread for a small array. Identical replicates give zero spread regardless of parent offsets. Verify normalization and missing-data behavior. Shuffle rollout rows to prove pairing follows identities, and check that unmatched arms cannot silently contribute. Use the existing score tests as prior art.
- At the penalty seam, compare Waveform and spectral values against the existing MPC reductions under matched references and normalization. Verify zero inside a connectivity interval and squared excess on each side. Check that fitting uses only reference runs. Use the existing MPC penalty parity tests as prior art.
- Check that dry-run creates no rollout stores and that the readers reject partial or incompatible artifacts. A full-size run validates the scientific protocol and produces the thesis evidence after the automated tests pass.

## Out of Scope

- Integrating connectivity into the MPC solver or changing existing Costs and production controller defaults.

- Writing final thesis claims before the renewed experiment runs.

## Further Notes

The original and renewed meeting notebooks are available in the local presentation directory, which is a symlink to a separate workspace. Both analysis notebooks load the same packaged score archive. The renewed slides retain the original meeting structure.

The first connectivity estimator and healthy interval are proposals. Imaginary coherency emphasizes lagged coupling and can miss genuine near-zero-lag coupling. Its trailing support may also dominate early-lookahead stability. Report those limits when interpreting the comparison. See [Nolte et al.](https://pubmed.ncbi.nlm.nih.gov/15351371/)

Store the experiment configuration, scored outputs, final figures, and results report together under the experiment artifact directory. Keep raw rollouts in temporary staging according to the experiment-packaging workflow.
